# Hoi! Nederlands

Онлайн-курси нідерландської мови — статична збірка сайту.

## Швидкий старт

Потрібен [Node.js](https://nodejs.org/) 18 або новіший.

```bash
npm start
```

Сайт відкриється на <http://localhost:4173>. Зупинити — `Ctrl+C`.

> Залежностей немає, тому `npm install` виконувати **не потрібно** —
> локальний сервер написаний на стандартній бібліотеці Node.

### Якщо термінал не бачить `npm`

Windows не оновлює PATH у вже запущених програмах. Якщо термінал або VS Code
стартували до встановлення Node.js, команда `npm` буде «не знайдена», доки
не перезавантажити систему.

Обхідний шлях — запуск, що читає актуальний PATH напряму з реєстру:

```powershell
.\start.ps1
```

Або подвійний клік на `start.cmd`. Порт задається так: `.\start.ps1 -Port 8080`.

## Структура

```
nederlands-school/
├── package.json          # скрипти запуску
├── README.md             # цей файл
├── ARCHITECTURE.md       # розбір вмісту збірки
├── start.ps1             # запуск в обхід застарілого PATH
├── start.cmd             # те саме, подвійним кліком
├── server/
│   └── dev-server.js     # локальний статичний сервер (без залежностей)
└── public/               # усе, що віддається браузеру
    ├── index.html        # HTML-оболонка з <div id="root">
    ├── favicon.svg
    └── assets/
        ├── script.js     # мініфікований бандл застосунку
        ├── styles.css    # скомпільований CSS
        └── fonts/        # локальні шрифти (DM Sans, Fraunces)
```

`public/` — корінь сайту. Щоб опублікувати проєкт на будь-якому статичному
хостингу (Netlify, Vercel, GitHub Pages, nginx), достатньо віддати саме цю теку.

## Команди

| Команда | Що робить |
|---------|-----------|
| `npm start` | Запускає локальний сервер на порту 4173 |
| `npm run dev` | Те саме |

### Налаштування

Змінні середовища:

| Змінна | Типово | Призначення |
|--------|--------|-------------|
| `PORT` | `4173` | Стартовий порт. Якщо зайнятий — візьме наступний вільний |
| `HOST` | `127.0.0.1` | Інтерфейс. Постав `0.0.0.0`, щоб відкрити доступ у мережі |
| `SITE_DIR` | автовизначення | Тека з `index.html` |

Приклад — запуск на іншому порту:

```bash
# PowerShell
$env:PORT=8080; npm start

# bash
PORT=8080 npm start
```

## Про сервер

`server/dev-server.js` — мінімальний статичний сервер без залежностей:

- коректні MIME-типи (зокрема `font/woff2` для шрифтів);
- захист від виходу за межі теки (path traversal);
- fallback на `index.html` для маршрутів без розширення;
- автопідбір вільного порту;
- `Cache-Control: no-cache`, щоб браузер не кешував правки під час розробки.

## Важливо знати

`public/assets/script.js` і `public/assets/styles.css` — це **готова
продакшн-збірка** (React 19 + Base UI + Tailwind v4), а не вихідний код.
Імена змінних стиснуті, сорсмапів немає. Редагувати їх вручну не варто.

Вихідний код — у репозиторії `hoi-nederlands-school/dutch-language-school`.
Зміни в логіці чи текстах робляться там, після чого проєкт перезбирається.

Детальний розбір того, що всередині збірки — секції сайту, рівні курсів,
структура тестів, звідки беруться дані — у [ARCHITECTURE.md](ARCHITECTURE.md).

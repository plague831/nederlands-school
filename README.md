# Hoi! Nederlands

Онлайн-курси нідерландської мови — односторінковий сайт на React 19.

## Швидкий старт

Потрібен [Node.js](https://nodejs.org/) 20 або новіший.

```bash
npm install
npm run dev
```

Сайт відкриється на <http://localhost:5173> з гарячим перезавантаженням:
правки в `src/` видно в браузері одразу. Зупинити — `Ctrl+C`.

### Якщо термінал не бачить `npm`

Windows не оновлює PATH у вже запущених програмах. Якщо термінал або VS Code
стартували до встановлення Node.js, команда `npm` буде «не знайдена», доки
не перезавантажити систему.

Обхідний шлях — запуск, що читає актуальний PATH напряму з реєстру:

```powershell
.\start.ps1
```

Або подвійний клік на `start.cmd`. Порт задається так: `.\start.ps1 -Port 8080`.
Скрипт сам встановить залежності, якщо `node_modules/` ще немає.

## Команди

| Команда | Що робить |
|---------|-----------|
| `npm run dev` | Сервер розробки Vite на порту 5173, з гарячим перезавантаженням |
| `npm run build` | Продакшн-збірка в `dist/` |
| `npm run preview` | Перегляд собраної версії засобами Vite |
| `npm run serve` | Віддає `dist/` власним сервером — так, як це зробить хостинг |
| `npm run typecheck` | Перевірка типів без збірки |

## Структура

```
nederlands-school/
├── index.html            # HTML-оболонка з <div id="root">
├── vite.config.ts
├── tsconfig.json
├── static/
│   └── favicon.svg       # копіюється у збірку без змін
├── src/
│   ├── main.tsx          # точка входу: createRoot + імпорт стилів
│   ├── App.tsx           # порядок секцій і діалогів
│   ├── site-state.tsx    # спільний стан сайту (контекст)
│   ├── assets/fonts/     # локальні woff2 (DM Sans, Fraunces)
│   ├── data/             # контент: курси, тести, уроки, FAQ, сценарії
│   ├── lib/              # дрібні утиліти (cn, плавний скрол)
│   ├── styles/           # CSS: токени, секції, адаптив
│   └── components/
│       ├── sections/     # секції сторінки
│       ├── dialogs/      # шість модальних вікон
│       └── ui/           # обгортки Base UI (діалог, кнопка, поле телефону)
├── server/
│   └── dev-server.js     # статичний сервер для dist/ (без залежностей)
├── start.ps1             # запуск в обхід застарілого PATH
└── start.cmd             # те саме, подвійним кліком
```

## Публікація

```bash
npm run build
```

Готовий сайт — у `dist/`. Це звичайна статика: віддай цю теку будь-якому
хостингу (Netlify, Vercel, GitHub Pages, nginx). Бекенд не потрібен.

## Стек

- **React 19** + TypeScript, збірка через **Vite**
- **Tailwind CSS v4** — утиліти для обгорток Base UI
- **Base UI** — безстильові примітиви, на них побудовані модальні вікна
- **lucide-react** — іконки

## Де що лежить

**Контент** — у `src/data/`. Тексти курсів, 30 питань тестів із поясненнями,
уроки програми, сценарії, FAQ. Щоб змінити ціну, додати питання або
переписати відповідь у FAQ, правити треба саме тут, а не в компонентах.

**Стилі** — у `src/styles/`. Файли імпортуються в `index.css` у фіксованому
порядку, і цей порядок має значення: пізніші перекривають ранніші
(наприклад `.hero` з `hero.css` перекриває `.hero` з `base.css`).
Кольори й радіуси — CSS-змінні в `:root` у `base.css`.

**Стан** — у `src/site-state.tsx`. Один контекст тримає відкрите модальне
вікно, вибраний курс, прогрес тесту, збережені слова та стан форм.

## Важливо знати

Бекенду немає. Форми «Надіслати заявку» та «Отримати демодоступ» нікуди не
відправляють дані — показують повідомлення в демонстраційному режимі.
Кнопка оплати теж заглушка. Стан живе лише в пам'яті React і зникає після
перезавантаження сторінки.

Детальніше про те, як усе працює — у [ARCHITECTURE.md](ARCHITECTURE.md).
